Privacy Policy

Link Spaces — Chrome extension · Last updated 3 September 2026

The short version: Link Spaces collects nothing, sends nothing, and has no servers. Everything you create stays in your own browser on your own computer.

What Link Spaces stores

Link Spaces stores only what you type into it: the names of your spaces, the links you add to them, and the colour you pick for each space.

This is saved using Chrome's storage.local API, which keeps the data on your device. It is never uploaded, synced to us, or shared with anyone. We have no way to see it.

What Link Spaces does not do

  • It does not collect personal information of any kind.
  • It does not track which pages you visit or how you use the extension.
  • It does not read the content of any web page. It holds no host permissions, so it technically cannot.
  • It contains no analytics, telemetry, advertising or fingerprinting code.
  • It makes no network requests of its own. The only requests are the ones your browser makes when you click one of your own links.
  • It has no accounts, no sign-in and no servers.

Permissions, and why each one exists

  • storage — to remember the spaces and links you create, so they are still there next time you open a tab.
  • contextMenus — to add the "Send this tab to Link Spaces" item to your right-click menu. When you click it, the address of the page you are on is added to the space you choose. Nothing happens unless you click it.
  • sidePanel — to show your spaces in Chrome's side panel.

Link Spaces requests no host permissions, which means it has no access to the content of any website you visit.

Data sharing and sale

There is no data to share or sell. Link Spaces transfers no user data to third parties, does not use data for any purpose unrelated to its single function, and does not use data for creditworthiness or lending.

Your data, your control

You can export everything to a JSON file at any time from the Export button, and delete everything by removing the extension — uninstalling clears its local storage.

Children

Link Spaces is a general-purpose tool and is not directed at children. Because it collects no data, it collects none from children either.

Changes to this policy

If this ever changes — for example if a future version adds optional sync — this page will be updated and the change described in the extension's listing before that version ships.
