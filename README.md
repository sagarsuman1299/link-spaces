# Link Spaces

**One tab for all your tools.**

A Chrome extension that turns your new tab into a short list of the places you
actually go. Each tool gets a space; each space holds the exact pages you use.
Click *Orders* and you land on Orders — not the homepage, not three clicks in.

---

## Why

Most people work across five or ten tools that have nothing to do with each
other — a store admin, an ads dashboard, an inbox, a seller account, a design
tool. None of them talk to each other, so you end up holding twenty tabs open
just so you don't lose your place.

Link Spaces exists so you can close them.

## What it does

- **Spaces** — group your links by tool, project, client or routine
- **One click to the exact page**, in the same tab (`Shift`+click for a new tab)
- **Search** across every link you've saved, from one box
- **18 ready-made packs** — Shopify, Meta Ads, Amazon Seller, LinkedIn,
  Instagram, Pinterest, Gmail, Google Analytics, Search Console, Drive,
  Calendar, YouTube Studio, X, GitHub, Canva, Stripe, Razorpay, GoDaddy.
  Pick one and its links arrive already filled in.
- **Right-click any page** → "Send this tab to Link Spaces" → pick a space
- **Side panel** (`Ctrl+Shift+K`) so your list stays put while you browse
- **Drag to reorder**, rename, recolour
- **Export / import** your spaces as a JSON file
- Follows your system light or dark mode

## Privacy

Link Spaces collects nothing. No accounts, no servers, no analytics.

It requests three permissions and no host permissions at all, which means it is
technically incapable of reading the pages you visit:

| Permission | Why |
|---|---|
| `storage` | remembers the spaces and links you create |
| `contextMenus` | the right-click "send this tab" item |
| `sidePanel` | the side panel view |

Your spaces are saved with Chrome's local storage on your own machine and never
leave it. The only network requests are the ones you make by clicking your own
links.

Full policy: <https://sagarsuman1299.github.io/link-spaces/>

## Install

From the Chrome Web Store — *listing pending review.*

Or run it unpacked:

1. Download or clone this repo
2. Open `chrome://extensions`
3. Turn on **Developer mode**
4. **Load unpacked** → select the extension folder
5. Open a new tab
